# Mogul Course Analyzer v1.8

Windows 11 / Python / PySide6による日本語デスクトップアプリです。
Phase 2（映像入力・エリア設定・ゲートとコブの登録）まで実装しています。人物追跡・人数集計・イベント解析は後続フェーズです。

## 起動

既存の`.venv`をそのまま使います。削除・再作成や依存関係の更新は不要です。

```powershell
Set-Location C:\work\MogulCourseAnalyzer
.\.venv\Scripts\python.exe -m mogul
```

起動時に録画済み動画またはUVCを選択します。保存済み設定がある場合は前回の復元を選べます。

```powershell
.\.venv\Scripts\python.exe -m mogul --video "C:\path\course.mp4"
.\.venv\Scripts\python.exe -m mogul --video "C:\path\sideways.mp4" --rotation 90
.\.venv\Scripts\python.exe -m mogul --database "C:\path\session.sqlite"
```

## 領域設定タブの操作

### 拡大表示と横倒し動画の回転

映像の上に表示操作を追加しています。

- **＋／－、マウスホイール**：全体表示比100〜3200%で拡大・縮小。ホイールはマウス位置を中心に拡大します。
- **中ボタンドラッグ／Space＋左ドラッグ**：表示位置を移動します。Space操作は映像ビューにフォーカスがある状態で使用してください。
- **全体表示**：映像全体が収まる状態に戻します。
- **ミドルを拡大**：指定したミドルパートへ余白付きで寄せます。初期設定前でもホイールで先に拡大してから四角形を作れます。
- **表示回転**：なし／右90°／180°／左90°。映像ソース選択時にも指定できます。

| 撮影方式 | 設定 |
|---|---|
| 横長のランドスケープ | 回転なし。必要な領域を拡大 |
| カメラを90度倒した横倒し映像 | 右90°または左90°で正立させてから設定 |
| スマホ等の縦長 | 縦横比を維持して表示。回転メタデータはデコーダーが補正し、通常は追加回転なし |

手動回転はメタデータ補正後の映像への追加補正です。向きが合わないファイルは回転方向を手動指定してください。映像を引き伸ばしたり、元動画を書き換えたりしません。
拡大は画面表示だけの変更で、座標や確認状態は変えません。再生・シーク・ウィンドウサイズ変更でも拡大率を維持します。ソース・解像度・回転の変更や再起動時は全体表示から始まります。

回転後のフレームを、表示・ミドルパート候補・ゲート候補等に共通して使用します。回転設定を保存・復元でき、既存の領域・レーン・ゲート・候補位置・コブ座標も同じ回転に追従します。内部ID・番号・スキーヤーL/Rを自動で付け替えません。横倒しのまま既に設定していた場合は、正立後に上流・下流とレーンの対応を再確認し、必要に応じて領域を再設定してください。

### 四隅とレーン

1. 動画はファイル選択。UVCはデバイス・解像度・FPSを選びます。機器が指定モードに対応している必要があります。
2. AIモデル未導入のため自動検出不可と表示します。映像上をドラッグして初期四角形を作り、四隅のマーカーをドラッグしてミドルパートに合わせます。
3. 映像内のマーカー以外をシングルクリックすると、ダブルクリック判別の待ち時間後に確定し、マーカーが消えます。
4. 確定した領域内をダブルクリックすると再編集できます。ミドルパートを再編集するとレーン再設定が必要です。Undoで戻せます。
5. ミドルパート確定後、2〜4レーンを指定して「手動均等分割で初期配置」を押します。これはAI検出ではありません。
6. 各レーンを選択し、共有境界の上下マーカーで補正し、映像内クリックで個別に確定します。レーン選択状態で領域内をダブルクリックすると再編集します。
7. Ctrl+SでSQLiteへ保存、Ctrl+ZでUndo。ResetもUndoできます。ソース変更・終了時は未保存変更の保存確認が出ます。

最左レーンの左上・左下、最右レーンの右上・右下もドラッグできます。四隅はゲート位置やミドルパート外周に固定せず、ミドルパート内で上下左右に動かせます。実際のコブ列に合わせて幅を狭め、ゲート側との余白を設定してください。約2mという現場の目安を固定ピクセルへ換算することはありません。

内部境界は隣接レーンと共有し、変更時は両側が未確定に戻ります。外側の頂点変更は対象レーンのみ未確定に戻します。レーン間の空白は共有境界で防ぎ、重複・範囲外・自己交差を拒否します。レーンがミドルパート全体を埋める必要はありません。詳細は[レーン修正仕様](SPEC_V1_8.md)を参照してください。

レーン名・色、領域不透明度（初期30%）、ミドルパート色、左右反転を変更できます。反転後は領域・レーンを再確認してください。

動画は再生・一時停止・シーク・前後1フレーム・0.25〜2倍速に対応します。現在位置を解析開始時刻にできます。UI編集中も再生を継続します。UVCはライブプレビューとMP4録画に対応し、切断時は3秒間隔で再接続を試みます。音声は扱いません。

## ゲート・コブ設定（Phase 2）

ミドルパートと全レーンを確定後、右側の「ゲート・コブ」タブを選びます。ゲート用の余白が必要なため、実際のコブ列へレーンを合わせて外側を狭めてください。

1. 操作ツールを「左ゲートをクリック追加」または「右ゲートをクリック追加」にし、映像内の旗をクリックします。ゲートはミドルパート内、最左／最右レーンの外側へ置きます。
2. 一覧でゲートを選択し、コース全体の番号（1〜9）を入力して「選択ゲートの位置・番号を確認」を押します。番号をミドルパート内で1から振り直しません。左右の本数は一致不要で、同じ番号の左右旗をY座標で自動対応させません。
3. 「選択・ドラッグ移動」で位置を補正できます。移動後は再確認してください。誤検出は削除、抜けは手動追加できます。
4. 「映っている全ゲートの設定を確定」を押します。同じ側の番号重複や上流・下流の逆順は拒否します。少なくとも1本必要です。
5. コブ一覧のタブで所属レーンと基準ゲート番号を選び、操作ツールを「選択レーン内をドラッグしてコブ追加」にします。映像上のコブを四角形で囲みます。
6. 同レーン・同ゲート内のコブ順序は次番号、ゲートが変わると1から初期設定します。表示ラベルは例 `B-3-2`。必要に応じて順序を修正し、スキーヤーから見た左右をL/R/UNKNOWNで選んで「選択コブのラベル・位置・左右を確認」を押します。UNKNOWNならL/Rをラベルに付けません。
7. 中心の移動は「選択・ドラッグ移動」、領域の修正は「選択コブの四隅を補正」を使います。小さいコブでも中心移動と四隅操作が干渉しないようツールを分けています。
8. 全レーンに1個以上のコブを登録・確認して「全レーンのコブ設定を確定」を押します。

「ゲートの色候補を抽出」は実画像の青・赤の色抽出です。**学習済みAIではなく、検出精度は未評価**です。候補は番号未設定・未確認として追加され、信頼度は未校正として保存します。必ず映像で修正・確認してください。コブは手動登録です。

「コースマップ」タブはミドルパートを透視変換した俯瞰模式図です。距離縮尺はありません。マーカーをクリックすると、映像上の同じゲート・コブを選択できます。凸四角形でない場合は画像座標の模式図になります。

レーンやミドルパートを変更してもゲート・コブの記録を削除せず、未確認に戻します。反転時は位置も反転しますが、スキーヤーのL/Rは変えません。確認・修正・削除はUndoで戻せます。

すべての設定が確認済みで入力も正常なら、画面下部の**「解析準備を保存」**が有効になります。これは位置設定を保存する操作です。人物検出・人数解析を動かす「分析開始」はPhase 3で追加します。

## 保存

既定は作業フォルダ内の`data/calibration.sqlite`です。「設定を復元…」で別のSQLiteも開けます。
正規化座標・共有境界・確定状態・レーン属性・表示設定・ソース情報・解析開始位置・検出状況を保存します。保存ごとのスナップショットと編集履歴を保持します。Undoは直近100操作で、再起動後は引き継ぎません。
ゲートの内部ID・全体番号・位置・候補位置・出所・信頼度・確認状態、コブの内部ID・所属レーン・中心・領域・基準ゲート・順序・スキーヤー左右・左右信頼度・確認状態も保存します。表示ラベルが変わっても内部IDは維持します。
追加回転角も保存します。旧データに回転角がなければ0度として読み込みます。拡大率と表示位置は保存対象外です。UVC録画ファイルは元の入力向きで保存し、セッション側に回転設定を保持します。
Phase 1のSQLiteは初回の更新保存前に同じ場所へ`.v1.bak`を作成し、スキーマ2へ更新します。旧保存スナップショットは書き換えません。
旧版の境界比率形式は読み込み時に正規化XY座標へ変換します。旧スナップショットは変更しません。修正版で保存した新形式は修正版アプリで復元してください。
元動画はコピーせずパスを参照します。移動した動画は元のパスに戻すか、新しい映像ソースとして設定してください。

録画はMP4（mp4v）と同名の`.timestamps.json`を生成します。JSONは各録画フレームのライブセッション内時刻（ミリ秒）です。欠落時は固定FPSのMP4時刻と一致しないため、この対応表を使います。

```powershell
.\.venv\Scripts\python.exe -m tools.check_uvc
.\.venv\Scripts\python.exe -m tools.check_uvc --device 0 --width 640 --height 480 --fps 30 --seconds 2
```

## 構成

| モジュール | 役割 |
|---|---|
| `mogul/app.py`, `source_selector.py` | 日本語GUI、入力選択、操作の接続 |
| `mogul/video.py` | VideoSource、File/UVC、録画、別スレッド処理 |
| `mogul/editor.py` | MiddlePartEditor / LaneEditor、透過表示、マウス操作 |
| `mogul/models.py`, `geometry.py` | 正規化モデル、共有境界、形状・領域計算 |
| `mogul/workflow.py` | CalibrationWorkflow、Undo、AnalysisControllerの開始条件 |
| `mogul/detectors.py` | MiddlePartDetector / LaneDetectorの差し替え契約 |
| `mogul/landmarks.py` | ControlGateDetector / Editor、BumpRegistry、データ・検証 |
| `mogul/landmark_panel.py`, `course_map.py` | ゲート・コブの操作パネル、非同期候補抽出、コースマップ |
| `mogul/orientation.py` | 回転・反転後の共通フレーム、保存座標の回転変換 |
| `mogul/repository.py` | EventRepository、SQLite保存・復元・履歴 |
| `tests/`, `tools/` | 回帰テスト、診断、合成動画生成、旧環境検証GUI |

既存環境のバージョンは[環境報告](ENVIRONMENT_V18.md)、履歴は[Phase 1報告](PHASE1_REPORT.md)、最新の結果・制約・残作業は[Phase 2報告](PHASE2_REPORT.md)に記録しています。
追加した拡大・回転の検証は[表示機能報告](VIEW_CONTROLS_REPORT.md)を参照してください。
`requirements.in`は直接依存、`requirements.txt`は固定バージョンです。今回の実装では依存追加なし。SQLiteはPython標準です。

AIモデル・学習データは同梱していません。ゲート候補はOpenCVのHSV抽出です。モデル採用時は前後処理、精度、CPU性能、メモリ、再配布条件を検証してください。
既存PATHのFFmpeg/ffprobeを使用します。FFmpeg 4.1.3は古く、すべてのコーデック・UVCを保証しません。実撮影の可変FPS・回転情報・HEVC/10bit・破損動画・長時間運用は追加検証が必要です。
`.venv/`、`data/`、`outputs/`、キャッシュはGitから除外します。
